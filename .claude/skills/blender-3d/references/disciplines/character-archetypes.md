
# Character Archetypes

Use this skill to lock silhouette, materials, and proportion language for a role/race before modeling.

## Load refs for family
Fantasy ancestries · Horror undead/monsters · Sci-fi bodytypes · Role kits (knight, ninja, detective, etc.)


## Appendix: fantasy-ancestries

# Fantasy Ancestries
Elf: tall, elegant, long lines. Dwarf: compact, heavy armor mass. Orc/Goblin: aggressive jaw/shoulder. Fairy: small scale, translucent wings.

## Appendix: horror-bodies

# Horror Bodies
Vampire: elegant + predatory. Werewolf: hybrid bulk. Ghost: soft transparency/trail. Zombie: decay asymmetry. Demon/angel: heraldic extremes. Mutant/beast: body-horror adjacent.

## Appendix: role-kits

# Role Kits
Knight/samurai/ninja/pirate/cowboy/soldier/detective/assassin/mercenary/superhero/villain/witch/wizard — signature props + silhouette must read at distance.

## Appendix: scifi-bodies

# Sci-Fi Bodies
Cybernetic: port seams, synthetic skin. Robot/android: panels vs human mimic. Mecha: pilot scale vs mech scale clarity.
