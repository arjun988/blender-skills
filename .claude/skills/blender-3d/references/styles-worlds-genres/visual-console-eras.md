# Visual Console / Media Eras

Match era constraints: polycount, texture filtering, lighting model, and post stack.


### Appendix: crt-vhs-film

# CRT / VHS / Film / DOS / Arcade
CRT scanlines + curvature (comp). VHS tracking. Film grain + slight gate weave. DOS: palette + dither. Arcade: neon cabinets, attract-mode contrast.

### Appendix: ps1-ps2

# PS1 / PS2
PS1: affine textures, low poly, vertex join cracks, no fancy mips. PS2: more tris, still crunchy, bloom beginnings, limited shaders.

### Appendix: ps3-ps5

# PS3 / PS4 / PS5
PS3: early deferred, baked AO common. PS4: PBR mainstream. PS5: denser geo, better GI, still readable game stylization — not raw film scans by default.
