# Indie Horror Aesthetics

Reference-driven indie horror looks. Pick a lane; don’t mash all at once.

## Load subtype refs
Silent Hill fog/rust; Fear to Fathom domestic analog; Puppet Combo PSX crunch; corporate/empty office; cabin/forest; hospital; urban decay.


### Appendix: corporate-horror

# Corporate Horror
Offices, cubicles, HR posters, fluorescent grids, empty conference rooms, logo uncanny.

### Appendix: fear-to-fathom

# Fear to Fathom Style
Domestic lowpoly, quiet forests/camps, flashlight cone, sparse props, analog UI feel.

### Appendix: location-horror

# Location Horror
Cabin: wood, fireplace, woods outside. Hospital: linoleum, curtains, gurneys. Forest: trails, fog, limited landmarks. Urban decay: stained concrete, graffiti, failing lights.

### Appendix: puppet-combo

# Puppet Combo Style
PSX crunch, VHS, motel/slasher sets, chunky characters, blood as graphic accent.

### Appendix: silent-hill

# Silent Hill Style
Fog wall, rust/blood metal, industrial otherworld, radio static spaces, streets emptied.
